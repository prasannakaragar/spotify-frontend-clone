# 🎧 Spotify UI Clone (HTML & CSS)

This is my **first frontend web development project**, built after about **one month of learning web development**.

I started by learning the fundamentals of **HTML and CSS**, and then challenged myself to build a real-world interface — a clone of Spotify’s web player UI.

At first, I thought building websites would be quite easy. But while working on this project, I truly understood that frontend development is **challenging, detail-oriented, and highly dependent on creative thinking**. This project gave me great hands-on experience in understanding how real websites are structured and styled.

---

## 🚀 Project Overview

A modern and responsive **Spotify Web UI Clone** built using only **HTML and CSS**, focusing on layout accuracy, clean design, and proper UI structure.

---

## ✨ Features

- Spotify-style dark theme interface  
- Sidebar navigation (Home, Search, Library)  
- Playlist and trending sections  
- Bottom music player UI  
- Responsive layout (desktop focused)  
- Clean and structured CSS styling  

---

## 🛠️ Built With

- **HTML5** – Page structure  
- **CSS3** – Styling, Flexbox, layout, responsiveness  

*(No JavaScript used)*
